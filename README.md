# Biblioteca

Aplicación en Java que gestiona una colección de libros mediante un arreglo.

## Instalación
1. Instalar JDK 17 o superior.
2. Clonar el repositorio: `git clone https://github.com/TU_USUARIO/Biblioteca.git`
3. Compilar: `javac -d out src/*.java`
4. Generar el JAR: `jar cfe bin/biblioteca.jar Main -C out .`

## Uso
Ejecutar: `java -jar bin/biblioteca.jar`
El programa crea una biblioteca, agrega cuatro libros y los muestra en consola.
